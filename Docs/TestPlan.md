## 자동 테스트

`Scripts/Build.ps1` 성공 후 `Scripts/Test.ps1 -EngineRoot '실제 경로'` 실행. `Saved/Automation/index.json`의 실패·성공 수를 확인합니다. 프로세스 종료 코드만으로 통과 판정하지 않습니다. GUI에서는 Tools → Test Automation 또는 Session Frontend → Automation에서 `Duskline` 필터를 실행합니다.

`Duskline.Components.Health`: 정확한 피해, 치유 상한, 치명 피해 제한, 반복 피해 무효, 사망 후 치유 무효.

`Duskline.Components.Stamina`: 고갈 후 공격·달리기 소비 실패, 회복 지연 경계, 회복률·상한, 음수 거절.

`Duskline.Components.Inventory`: 중첩 상한, 슬롯 부족 부분 처리, 무게·가치 계산, 초과 제거 처리량, 빈 슬롯 제거, 무게 초과·null 아이템 거절.

`Duskline.Components.Medicine`: 최대 체력 시 미소비, 1개 소비, 실제 회복량 상한, 빈 슬롯 제거, 의약품 부재.

엔진 독립 테스트는 `Tests/RulesTest.cpp`입니다. VS x64 Native Tools Command Prompt에서 다음을 실행합니다.

```bat
cl /nologo /std:c++17 /EHsc /W4 /WX Tests\RulesTest.cpp /Fe:RulesTest.exe
RulesTest.exe
```

테스트 대상은 실제 GameState·Inventory에서 호출하는 `RunRules.h`입니다. 시간 경계·종료 불변성·탈출 조건·무게 계산 20개를 검증합니다. UI나 엔진 객체 수명 검증은 포함하지 않습니다.

| 이동 | WASD, 마우스, Space, Ctrl | 3인칭 이동, 점프, 천장 아래 안전한 웅크리기 |

| 공격 중복 | 같은 적을 여러 sweep hit가 덮도록 공격 | 한 입력당 피해 한 번, 쿨다운 준수 |
