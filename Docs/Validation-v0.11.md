# v0.11 — 모션 정렬과 지역 기록

- 네 캐릭터의 보행 프레임에서 투명 여백을 제외한 높이를 측정하여 발 기준 크기 보정. 공격 자세에는 기존 시트별 몸 크기 보정을 유지.
- 강화 검날이 최종 캐릭터 배율과 회전을 따르도록 수정. 별도 스킬/협공 자세에는 맞지 않는 기본 검날 오버레이를 숨김.
- 은닉처에서 지역 기록 7종 수집: 배급 명부, 정비소 호출부호, 약국 기록, 옥상 신호, 배수관 점검표, 재희의 장부, 성채 운송표.
- 스토리 진행에 따라 기록 해금. 안전 귀환 시 영구 보관, 수색 실패 시 이번 수색의 미보관 기록 유실. 기존 저장 호환.
- I 기록 메뉴에서 좌우 방향키 또는 A/D로 8페이지(현황 + 기록 7종) 탐색.
- 기존 지형과 은닉처에 세계관 수집 요소를 추가한 버전이며 새로운 지형이나 다음 메인 장을 추가한 것은 아님.

검증: 모델 검사 172개 통과, Unity Windows 빌드 오류 0 / 경고 0. 보행/공격/스킬 실행 화면 검사 결과는 Validation에 보관.
