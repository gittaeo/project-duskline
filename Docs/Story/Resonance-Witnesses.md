# 공명 설계도 — 4장 병행 이야기

태오: 청록 목도리와 무전기를 지닌 잘생긴 정찰자. 옥상 공동체와 제7대피소 사이의 연락을 담당한다. 무모한 구조보다 돌아올 길을 먼저 확보하는 신중함을 지녔다. 4장부터 쉘터 1층에서 대화한다.

이수형: 성채 운송 경비대 출신. 보랏빛 결정 감염이 팔과 얼굴을 잠식했으나 이름과 동료의 호출부호는 기억한다. 감염자를 일괄적으로 적으로만 볼 수 없다는 갈등을 제공한다. 폐철도 입구 58m에서 대화하며 주변 4m 안의 적을 먼저 정리해야 한다.

현재 플레이 흐름: 태오의 단서 → 이수형과 대화 → 공명 설계도 회수 → 안전 귀환 → 공용 LV4 조건을 충족한 캐릭터별 고유 무기 제작. 실패하면 설계도를 다시 회수해야 한다. 태오 대화는 안내이고 선행 강제 조건은 아니다.

기존 형 강준의 운송표 수색과 병행하는 이야기다. 이수형의 치료나 생존, 태오의 정식 동료 합류는 이 버전에서 확정하지 않는다.
