# v0.13 개발 명세 — 일관된 모션과 생존 성장

작성: 2026-10-14. 기존 v0.12를 확장하며 사용자 최신 요청을 우선한다.

## 목표와 구현 순서
1. 캐릭터의 서기·보행·공격 전환에서 몸 크기와 발 기준점을 유지한다. 무기나 뻗은 팔까지 포함한 전체 이미지 높이로 인체를 확대하지 않는다. 포즈별 보정과 짧은 크기 전환을 사용한다.
2. 공용 무기를 LV6까지 완성한 뒤 고유 무기 제작을 허용한다. 기존 저장의 제작된 고유 무기는 유지하되 추가 제작/각성에는 새 조건을 적용한다. 고유 무기는 원본에 그려진 무기를 유지하며 공명 각성으로 성장한다. 별도 무기 이미지를 덧씌우거나 교체하지 않는다. 하린은 제작 시 전직 분기(연사 사수 / 관통 포격수)를 고르고, 동작·사격 간격·범위와 연출이 달라진다. 쉘터에서 분기 재선택을 허용한다.
3. 기존 스토리 문서 4장 후반의 비축품 약탈·재희의 자백·연우 이동 사실·피해 복구를 두 수색 임무로 추가한다. 성채 본편 전체나 연우 구조 완료를 미리 주장하지 않는다.
4. 귀환·출정·실제 습격은 체력을 무료로 채우지 않는다. 체력은 저장/로드에 보존한다. 전투 불능 실패는 체력1로 구조되어 침대나 치료가 필요하다. 연습 습격은 입장 전 체력으로 복구한다.
5. 침대 휴식은 시간과 식량/물을 사용해 회복한다. 자원 고갈로 진행이 막히지 않도록 느린 최소 응급 휴식으로 체력30까지만 회복 가능하게 한다. 이미 만피일 때 자원을 쓰지 않는다.
6. 재배는 파종(종자1·물3) → 물자를 가져오는 성공 수색 2회 → 직접 수확(식량4·약초2·종자1)으로 구분한다. 실패나 빈손 귀환, 반복 클릭으로 자원이 복제되지 않는다. 기존 재배 시설은 유지하며 새 파종부터 적용한다.
7. B 키 인벤토리에 자원/치료품/장비/아티팩트를 분리한다. 붕대·약·회복 아티팩트의 소지량과 효과를 표시하고 실제 사용할 수 있게 한다. 약초와 물로 약을 만들고, 약과 보스 코어로 소모형 회복 아티팩트를 만든다. I는 기존 이야기 기록으로 유지한다.

## 검수 기준
- 기본/고유 무기의 서기·걷기·3단 공격·스킬, 좌우 방향과 태그를 실행 화면에서 확인.
- LV5 제작 차단, LV6 비용/개인 소유/전직 분기/저장 호환 검사.
- 체력 유지, 실패 구조 체력, 휴식 중복 차감 방지, 치료 만피 차감 방지 검사.
- 파종 비용, 실패 성장 금지, 수확 준비 및 한 번만 수확, 제작/아이템 소비/저장 검사.
- 새 임무의 실패/성공/반복귀환 및 스토리 상한 검사.
- D드라이브에 새 실행 빌드, 변경 명세와 캡처를 저장소에 포함.

## 2026-10-16 최종 아트 방향
- 사용자 결정에 따라 무기 교체/파츠 장착 방식을 제거한다.
- 원본 캐릭터와 무기, 손의 연결을 그대로 보존한다.
- 강화와 고유 각성은 무기 표면의 발광, 잔상, 다층 검격, 충격파, 총구 광선, 전기 궤적으로 구분한다.
- 각성 1~3단계에 따라 밝기·레이어 수·폭을 높인다. F2 연출 완화 설정을 유지한다.
- 모션별 좌표는 무기 끝의 빛과 발사 효과에만 사용하며 캐릭터 픽셀을 지우지 않는다.
