# 황혼선 — 쉘터 생존 RPG PRD

버전: 0.14 / 작성일: 2026-10-09 / 수정일: 2026-10-14 / 상태: v0.10 크기 보정·4장 전반 시제품, 아래 구현 현황 참고

표기: [확정] 사용자 명시·응답 / [채택] 사용자의 세부 설계 위임에 따라 선택한 제작 기준 / [제안] 검토용 기본안 / [미정] 미결 사항.
2026-10-11: 사용자가 세부 추천안 진행을 위임하고 완성 가능성을 우선하도록 요청했다. 아래 14절의 채택안이 앞선 제안·미정 항목보다 우선한다. 사용자 직접 확정과 위임에 의한 채택을 구분한다.
이 문서의 제안·예시 수치는 확정 요구사항이나 구현 완료 사항이 아니다.

## 1. 제품의 중심

[확정] 좀비를 피해 횡스크롤 지역을 수색하고 자원을 회수하여, 주어진 쉘터와 그곳의 사람들을 유지·발전시키는 2D 생존 RPG.

핵심 질문: “이번 수색에서 무엇을 가져와야 우리 쉘터의 내일이 나아질까?”

- [확정] 주인공을 따라가는 2D 횡스크롤 시점. 기존 탑다운 전체 미로 화면을 대체한다.
- [확정] 4~5등신 세미리얼 도트. 기존 2등신 일러스트를 축소한 표현은 최종 아트 기준이 아니다.
- [확정] 쉘터의 유지·성장이 장기 플레이의 중심이다.
- [확정] 스토리 스테이지 진행에 따라 NPC가 합류하고, 쉘터에 배치되어 활동·혜택을 제공한다.
- [확정] NPC가 자원 획득에 영향을 주는 요소를 포함한다. 적용 대상·확률 공식은 미정이다.
- [계승 요구] 수색 자원으로 검·표창·총을 제작하고 강화한다. 각 무기의 최종 세부 규칙은 횡스크롤 전투 설계에 맞춰 다시 정한다.

## 2. 플레이 구조

[제안] 쉘터 점검 → 부족 자원/주민 요청 확인 → 목적지·장비·물자 선택 → 횡스크롤 수색 → 위험과 추가 수확 중 선택 → 생존 귀환 → 자원 배분·NPC 배치 → 스토리/시설 개방.

| 구간 | 플레이어의 선택 | 체감 결과 |
|---|---|---|
| 출발 준비 | 의약품이 부족하면 약국, 전력이 부족하면 정비소 | 수색 장소가 운영 목표와 연결됨 |
| 수색 | 조용한 우회로 / 위험하지만 보상이 좋은 내부 | 좀비를 모두 죽이지 않아도 진행 |
| 귀환 판단 | 더 깊이 들어가기 / 현재 물자로 복귀 | 회수 성공 자체가 의미 있는 성취 |
| 쉘터 배분 | 무기 강화 / 발전기 수리 / 식량 확보 | 하나의 자원에 실제 기회비용 발생 |
| 인력 배치 | 기술자를 작업장 / 발전실 중 어디에 둘지 | 인물마다 역할과 운영 선택이 생김 |
| 다음 목표 | 새 주민 요청 / 다음 스테이지 / 재수색 | 다음 접속 목적을 자연스럽게 제시 |

[제안] 1회 수색 8~15분, 귀환 후 운영 3~5분. 최종 길이는 사용자 결정과 실제 플레이 검증으로 조정한다.

## 3. 횡스크롤 탐험과 카메라

- [확정] 플레이어 주변 일부만 보여주는 횡스크롤 카메라. 기본 화면에서 전체 지역을 노출하지 않는다.
- [제안] 좌우 이동, 짧은 점프, 사다리, 문으로 연결된 실내. 정밀 점프 시험보다 탐색·위험 판단을 우선한다.
- [제안] 지상 골목·건물 내부·옥상·지하의 연결로 탐험 분기를 만든다. 화면 깊이 방향 자유 이동은 MVP에서 제외한다.
- [제안] 이동 방향을 조금 앞서 보여주는 카메라, 방 진입 시 부드러운 전환, 피격 흔들림 조절/끄기.
- [제안] 지도는 발견한 구간을 보여주는 별도 화면. 출구와 목표는 탐색 또는 정보 획득으로 표시한다.
- [미정] 직접 설계한 고정 스테이지 / 고정 뼈대에 전리품·적 변주 / 전체 절차 생성 중 선택.

## 4. 수색·회수·전투

- [제안] 좀비는 시야와 소음으로 반응한다. 은신·소리 유인·문 봉쇄·회피를 전투와 동등한 해법으로 둔다.
- [제안] 검은 탄약이 필요 없지만 접근 위험, 표창은 제한 수량과 저소음, 총은 높은 화력과 큰 소음으로 구분한다.
- [제안] 자원 무게 또는 가방 칸 때문에 모두 가져갈 수 없게 한다. 제한 방식은 미정이다.
- [제안] 일반 수색은 출구에서 귀환 가능. 스토리 진행은 목표 달성 후 생존 귀환 시 확정한다.
- [확정] 수색 실패 시 이번 수색에서 획득한 물자의 일부만 잃는다. 기존 보관 자원·장비·NPC는 유지한다.
- [미정] 손실 비율, 품목별 반올림, 퀘스트 물품 처리. [제안] 실패 화면에 회수분과 손실분을 구분하며, 손실 판정은 한 번만 저장한다.
- [제안] 죽음을 통한 무료 운반, 저장 불러오기로 보상 중복 수령, 무한 자원 회수는 막는다.

### 수색 에너지

- [확정] 수색은 에너지를 소비하며, 시간이 지나면 자동 충전된다.
- [확정] 충전 속도: 실제 시간 15분마다 에너지 1 회복(2026-10-09 응답).
- [사용자 예시·수치 미확정] 최대 에너지 20, 수색 1회 비용 4. 이 수치 적용 시 가득 찬 상태에서 연속 5회, 0에서 1회분 회복 1시간, 완충 5시간이다.
- [제안] 에너지로 출정 빈도를 제한하며 별도의 자정 초기화 일일 횟수 제한은 두지 않는다. 최대 20은 하루 총 5회 제한을 뜻하지 않는다.
- [제안] 앱 종료 중에도 실제 경과 시간으로 충전하고 최대치에서 멈춘다. 최대치 이후 시간은 다음 충전으로 비축하지 않는다. 최대치 미만의 15분 미만 잔여 시간은 저장·재접속 시 유지한다.
- [제안] 출정 확정 시 비용을 한 번만 차감하고 실패 시 환급하지 않는다. 로딩 실패는 환급하거나 동일 출정으로 복구한다. 재접속으로 중복 차감되지 않는다.
- [제안] 현재 에너지, 다음 1 회복까지 시간, 선택 지역 출정 가능까지 시간을 표시한다. 에너지 없이 가구 배치·제작·주민 대화를 할 수 있다.
- [미정] 지역별 비용 차등, 회복 아이템, 최대치 성장. 광고·유료 충전은 요구사항으로 추가하지 않는다.
- [구현 시 결정] 오프라인 게임은 저장한 시각으로 충전을 계산하되 기기 시각 변경에 취약하다. 온라인 운영 채택 시 서버 기준 시각을 사용한다. 플랫폼·네트워크 정책 결정 후 확정한다.

## 5. 쉘터 운영

[확정] 쉘터는 주어진 거점이며, 수색으로 유지·발전시킨다.
[확정] 자유로운 건축·꾸미기와 부족한 자원 관리를 함께 제공한다. 가구·설비 설치가 자원 관련 이익을 주어 배치와 운영이 연결되어야 한다.

[제안] 횡단면 건물에서 방과 주민의 일상을 보여주며 가구·설비를 직접 배치한다.
[확정] 주어진 건물 안에서 가구·설비를 자유롭게 배치하고 방을 확장한다(2026-10-11 응답). 벽·바닥·방 구조를 처음부터 직접 설계하는 건축은 현재 범위에 포함하지 않는다.
[제안] 수색으로 얻은 자원으로 잠긴 방을 복구·개방한다. 방별 공간과 배치 가능한 위치 안에서 생산·생활·장식 가구를 조합한다. 방 개방 비용과 순서는 추후 결정한다.

| 시설 [제안] | 자원 사용 | 주요 기능 | 화면 속 NPC 활동 |
|---|---|---|---|
| 창고 | 목재·금속 | 보관 용량, 재고 우선순위 | 분류·운반·점검 |
| 작업장 | 금속·부품·전력 | 검·표창·총 제작 및 강화 | 공구 사용·장비 수리 |
| 주방 | 식량·물·연료 | 배급, 수색용 식사 | 조리·설거지·배급 |
| 의무실 | 약재·의약품 | 부상·피로 회복 | 치료·휴식 |
| 발전실 | 연료·부품 | 시설 전력 공급 | 발전기 점검·수리 |
| 무전실 | 전자부품·전력 | 수색 정보, 스토리 신호 | 통신·지역 조사 |

### 가구와 자원 효과

[확정] 설치한 가구·설비가 자원 획득·생산·관리 효과를 제공한다. 구체적인 가구와 수치는 아래 제안이다.

| 가구·설비 [제안] | 효과 | 운영 선택 |
|---|---|---|
| 재배 상자 | 일정 시간마다 식량 생산 | 물과 공간 사용 |
| 빗물 저장통 | 물 생산·저장 | 설치 가능 구역과 보관 한도 |
| 공구 작업대 | 특정 제작 재료 소모 감소 | 전력·기술자 배치와 연계 |
| 정찰 지도판 | 다음 출정의 특정 자원 발견 확률 증가 | 정찰원 배치와 연계 |
| 수납 선반 | 쉘터 자원 보관 한도 증가 | 생산 설비와 공간 경쟁 |
| 침대·생활 가구 | 주민 회복 또는 쾌적도 개선 | 간접 생산 효율 개선 |

- [제안] 배치 전 설치 비용, 효과 대상, 생산 주기, 유지비, 작동 조건과 합산 결과를 표시한다. 자원 수량 증가·발견 확률 증가·저장량 증가는 별도로 표기한다.
- [제안] 이동은 무료이며 배치 취소 시 재료를 차감하지 않는다. 철거 환급률은 별도 결정한다.
- [제안] 중복 효과의 상한과 작동 조건을 명시한다. 설치·철거 반복으로 생산 타이머를 초기 보상처럼 악용할 수 없어야 한다.
- [제안] 가구 점유 영역·출입구·NPC 이동 경로를 검증한다. 장식은 운영 효과 외에도 외형 선택의 가치를 가진다.

### 운영 원칙 [제안]

- 생산량, 주민 소비, 다음 정산 시 예상 부족분을 출발 전에 보여준다.
- 식량·전력·의약품 중 실제 선택을 만드는 소수 지표부터 시작한다.
- 부족은 단계적으로 효율·회복에 영향을 주며, 예고 없이 쉘터를 파괴하지 않는다.
- 필수 자원과 에너지가 모두 0이어도 회복 경로가 존재해야 한다. 에너지 자연 회복은 쉘터 자원을 요구하지 않으며, 기본 출정에 소모성 식량·장비를 필수로 요구하지 않는 안을 검토한다.
- NPC가 쉘터를 지원하더라도 플레이어의 수색 필요성이 완전히 사라지지 않게 한다.
- [확정] 수색 에너지는 실제 시간으로 회복한다. [채택] 오프라인에는 생산물이 전용 보관 한도까지 쌓이고 주민 소비는 멈춘다. 상세 정산은 14절을 따른다.
- [미정] 스토리의 날짜·낮밤 변화는 에너지 시계와 별도로 정한다.
- [미정] 좀비의 쉘터 습격과 방어전 포함 여부.

## 6. 스토리·스테이지·NPC 합류

- [확정] `10-1` 같은 번호 체계를 사용할 수 있다. 10개 챕터나 모든 스테이지당 NPC 1명은 아직 확정하지 않는다.
- [제안] `챕터-스테이지`로 구분하며 스토리 최초 클리어와 반복 수색 보상을 분리한다.
- [제안] NPC는 지정된 스토리 이정표에서 합류한다. 같은 스테이지 반복으로 같은 NPC를 복제하지 않는다.
- [미정] NPC가 모든 클리어마다 등장할지, 일부 스테이지에서만 합류할지.
- [미정] 자동 합류 / 현장 구조 후 귀환 / 대화 선택·개인 퀘스트 후 합류 방식.

### 예시 진행 [모두 제안, 실제 스토리 미확정]

1. `1-1 끊어진 불빛`: 식량을 회수하고 임시 쉘터를 가동한다.
2. `1-2 정비소의 신호`: 기술자를 구조하고 작업장과 발전실 중 첫 배치를 선택한다.
3. `1-3 약국 뒤편`: 의약품과 의료 NPC의 단서를 획득한다.
4. 후속 임무: 기술자의 개인 부탁을 해결하면 새 설비 제작법 또는 특성이 열린다.

## 7. NPC 시스템

[제안] 각 NPC는 고유 이름·직업·특성·개인 목표를 가진다. 역할·효과 외에 쉘터에서 보이는 생활 행동과 대화가 있어야 한다.

최소 데이터: 고유 ID, 합류 조건, 배치 시설, 직무 등급, 피로/부상 상태, 신뢰도, 개인 퀘스트 진행, 대화 상태.

| 직업 [제안] | 배치 선택과 효과 예시 | 서사·일상 |
|---|---|---|
| 정찰원 | 무전실: 다음 출정의 지정 자원 발견 기회 증가 | 지도 표시·정찰 보고 |
| 기술자 | 작업장: 제작 효율 / 발전실: 연료 효율 중 선택 | 망가진 설비 복구, 개인 공구 찾기 |

| 요리사 | 주방: 식량 활용과 수색 식사 제작 | 공동 식사와 주민 반응 |
| 경비원 | 방어 관련 기능 채택 시 설계 | 순찰·피난 경험 대화 |

### 배치·효과 규칙 [제안]

- 한 NPC는 동시에 한 직무에만 배치한다. 생산·휴식·부상 상태를 구분한다.
- 장비·시설·NPC의 효과를 출발 전에 요약한다. 출정 중 배치 변경으로 확률을 재추첨하지 않는다.
- 확률 보너스는 “추가 판정”과 “수량 증가”를 구분한다. 표기에는 퍼센트와 퍼센트포인트를 혼용하지 않는다.
- 예시 공식: 최종 추가 발견 확률 = min(상한, 기본 확률 + 정찰 보너스 + 시설 보너스). 기본 20%, 보너스 +5%p라면 최종 25%. 수치는 예시이며 밸런스 확정이 아니다.
- 종류별 상한과 중복 규칙을 둔다. 같은 특성을 누적해 100% 이상의 확률이나 무한 생산이 생기지 않게 한다.
- 최초 합류·개인 퀘스트 완료 보상은 저장 후에도 한 번만 지급한다.
- [미정] 동료의 현장 동행, 호감도 깊이, 갈등·이탈·사망 여부.

## 8. 자원·제작·성장

[제안] 기본 자원을 식량, 물, 금속, 섬유, 전자부품, 연료, 의약품으로 시작한다. 최종 목록은 운영 압박 선택 후 줄이거나 묶는다.

- 식량·물 → 거주민 유지와 출정 준비.
- 금속·섬유 → 무기와 시설 사이의 투자 선택.
- 부품·연료 → 전력·통신·시설 발전.
- 의약품 → 치료와 위험한 수색의 준비.
- 퀘스트 물품 → 스토리 진행; 일반 제작으로 실수 소비되지 않는다.

[제안] 성장은 무기 단계, 시설 단계, 주민 역량, 스토리 개방의 네 축으로 구성한다. 동일 재료로 시설과 무기가 무한히 강화되는 구조는 피한다.
[미정] 플레이어 레벨·스킬 트리, 무기 내구도, 등급·랜덤 옵션, 기존 최대 5단계 유지 여부.

참고 영상에서 채택할 요소는 측면 시점, 레이어가 있는 공간, 배경과 인물을 구분하는 빛, 캐릭터 중심 화면 구성이다. 영상의 판타지 세계관·기존 캐릭터·보스·UI를 복제하지 않는다.

### 제작 제안

- 기준 해상도 640×360과 960×540을 같은 한 장면으로 비교한 뒤 하나를 고정한다. 숫자는 아직 미확정.
- 캐릭터 키 약 80~120 원본 픽셀을 후보로 테스트. 화면 비율·픽셀 밀도·카메라 배율을 먼저 고정한다.
- 인물·무기·타일은 같은 픽셀 밀도와 제한된 색상 규칙을 사용한다.
- 단순히 큰 일러스트에 모자이크 필터를 씌운 결과를 최종 도트로 인정하지 않는다.
- Point 샘플링, 정수 배율/픽셀 정렬을 기본으로 검토한다. 이동 중 반짝임·떨림이 없어야 한다.
- 전경·중경·원경과 제한된 안개·먼지·비·광원을 사용하되 적의 공격 예고와 발판을 가리지 않는다.
- 달리기, 멈춤, 공격 준비, 타격, 회수, 피격, 회피의 리듬을 분리한다. 공격 판정은 보이는 접촉 순간과 일치한다.
- 무기를 바꾸면 손에 든 무기와 공격 동작도 바뀐다. 검을 든 그림 위에 총 아이콘만 붙이지 않는다.
- 쉘터의 조명·시설 외형·인물 활동이 발전 단계에 따라 실제로 변한다.
- 환경음·발소리·재질별 타격음·무전 대사로 수색의 불안과 귀환의 안도감을 구분한다.

### 대량 제작 전 합격 조건 [제안]

주인공 1명, 좀비 1종, 외부 골목 1구간, 쉘터 방 1개를 실제 플레이 크기에서 검토한다. 정지 원화만으로 승인하지 않는다. 이동·공격·피격·조명 대비와 30초 실제 플레이를 확인한 후 에셋을 확장한다.

- 승인된 도트 기준이 실제 플레이 화면과 애니메이션에서 유지된다.
- 성능 기준은 대상 플랫폼·최소 사양을 결정한 뒤 수치화한다.

## 14. 완성 가능한 제작 기준 — 2026-10-11 채택

이 절은 구현 완료 보고가 아니다. 다음 제작의 범위와 검증 순서를 정한다. 앞선 절의 미정·제안과 충돌하면 이 절을 적용한다.

### 첫 완성판의 고정 범위

- Windows PC 싱글플레이, 키보드·마우스, 로컬 저장. Unity 6.2의 2D SpriteRenderer·Tilemap 기반으로 제작한다. 외부 계정·서버·결제·멀티플레이는 첫 완성판에 넣지 않는다.
- 한국풍 가상 도시의 한 구역: 골목 → 정비소 → 약국으로 이어지는 직접 설계한 짧은 횡스크롤 임무 3개. 같은 배경 구간을 일부 재사용하고 전리품·적 배치만 변주한다. 전체 절차 생성은 제외한다.
- 첫 3개 임무와 쉘터 복구 목표를 달성하면 작은 결말을 제공한다. 이후 반복 수색과 무기·가구 개선이 가능하다. 목표 분량은 첫 진행 약 30~45분이며 실제 플레이 후 조정한다.
- 주인공 1명, 일반 좀비와 돌진 좀비 2종, 구조 NPC 2명(기술자·의료인). NPC 현장 동행 AI는 제외하고 쉘터 행동과 역할 효과를 구현한다.
- 검·표창·총 각 1종, 각 3단계 강화. 방어구 랜덤 옵션·대형 스킬 트리·내구도는 제외한다.
- 쉘터 시작 방 1개와 복구해 여는 방 1개. 기존 건물의 바닥 격자에 가구를 자유 배치하며 이동 경로를 보장한다. 벽·바닥 직접 편집은 없다.
- 가구 6종: 작업대, 재배 상자, 빗물 저장통, 수납 선반, 침대, 의료 선반. 생활·생산 가구 자체도 꾸미기 요소가 되며 색·조명으로 개성을 준다. 대규모 장식 카탈로그는 이후 확장한다.
- 자원 6종: 식량·물·금속·섬유·부품·의약품. 첫 완성판에는 발전·연료망을 생략한다. NPC는 기술자가 작업대, 의료인이 의료 선반에 배치되어 눈에 보이는 활동을 한다.

### 수색과 운영의 초기 규칙

- 에너지 최대 20, 출정 비용 4, 15분마다 1 회복. 별도 일일 횟수 제한 없음. 출정 확정 시 차감, 실패 시 미환급, 로딩 실패는 복구 또는 환급. 재접속 시 진행 중 출정을 복원한다.
- 한 임무는 목표 달성 후 귀환으로 완료한다. 중도 귀환은 물자를 보관하되 스토리 목표는 미완료다. 실패 시 일반 수색 물품은 품목별 70%를 내림해 회수하고 나머지를 잃는다. 퀘스트 물품과 NPC 합류는 성공 귀환 시에만 확정한다. 이 70%는 테스트 가능한 초기 밸런스다.
- 좀비 공격은 명확한 준비 동작 후 판정한다. 검은 자원 부담이 적고, 표창은 저소음·제한 수량, 총은 화력·탄약·소음의 교환 관계를 갖는다. 이동·점프·상호작용·공격·회피만 먼저 구현한다.
- 일반 출정에 식량·물은 필수 입장 비용이 아니다. 검은 탄약 없이 사용 가능하며 기본 에너지 회복에 자원이 들지 않아 빈곤 상태에서도 재출발할 수 있다.
- 접속 중 식량·물은 거주민 수에 비례해 일정 주기로 소비한다. 부족하면 생산 효율이 낮아지며 사망·시설 파괴는 없다. 소비 주기와 양은 조절 가능한 데이터로 둔다.
- 오프라인에는 재배 상자와 빗물 저장통만 자체 생산한다. 입력 재료가 필요 없는 저속 기본 생산이며 전용 저장 한도에서 멈춘다. 주민 식량·물 소비는 중지한다. 제작은 수동 즉시 처리하므로 복잡한 오프라인 제작 큐는 없다.
- 재배 상자의 식량은 인접한 생산 재고에 저장하고 자동 주민 소비는 하지 않는다. 수령 시 중앙 창고의 남은 용량만큼 옮기고 초과분은 생산 재고에 남긴다. 빗물도 같은 규칙이다.
- 오프라인 정산은 저장된 마지막 정산 시점부터 한 번만 계산한다. 가구 이동으로 생산 타이머가 초기화되지 않으며 저장 한도 이후 생산은 비축하지 않는다. 로컬 시계 조작 방지는 첫 싱글판의 보장 범위 밖이며 음수 경과 시간은 0 처리한다.
- 가구는 배치 확정 때 자원을 차감하고 이동은 무료다. 철거는 판매·재료 환급 대신 가구 보관함으로 회수한다. 생산 잔고와 타이머도 해당 가구 ID에 귀속한다. 보관 중에는 생산·효과가 중지된다.
- 동종 효과는 명시된 상한까지 합산한다. 배치 UI에 효과·점유 공간·작동 상태를 보여준다. 건물 출입구와 주민 이동 길을 막는 배치는 확정할 수 없다.

### 구현 구조

데이터는 ItemData, WeaponData, RecipeData, FurnitureData, NpcData, MissionData로 분리한다. 진행 상태는 데이터 원본과 별도로 저장하며 인벤토리·제작·에너지·쉘터·임무·저장이 서로의 UI를 직접 호출하지 않는다. 상태 변경 이벤트를 UI가 구독한다. 즉시 계산에 불필요한 async나 코루틴을 추가하지 않는다.

SaveData에는 버전, 보관 자원, 무기 단계, 가구 고유 ID·위치·생산 재고, 방 개방, NPC 배치, 임무 완료, 에너지·충전 기준 시점, 진행 중 출정을 포함한다. 임시 파일 기록 후 교체와 백업 복구로 저장 손상을 줄인다. 보상 지급과 임무 완료는 같은 저장 상태로 반영한다.

Glade 연결은 기존 Unity 프로젝트를 백업한 뒤 작은 시험 씬에서 생성·수정·저장·재실행으로 검증한다. 연결 문제가 있어도 C#·에디터 도구·Unity 빌드로 제작을 계속할 수 있게 하며, Glade 설치 성공을 게임 제작의 필수 전제에 두지 않는다. 새 도구·캐시·에셋·배포 경로는 설정 가능한 범위에서 D드라이브를 사용한다.
