# v0.13 각성 연출 규칙

2026-10-16 사용자 결정: 원본 캐릭터에 그려진 무기를 유지한다. 별도 무기 이미지 교체, 손/무기 지우기 마스크, 장착 전환은 사용하지 않는다.

공용 LV3부터 원래 무기 위에 빛이 흐른다. 고유 각성은 4층 발광과 전류 궤적, 각성색 잔상, 공격 시 최대12층 에너지로 강화된다. 이현은 청백 검격, 도윤은 주황 충격파, 하린은 민트 총구 광선, 세린은 보라 번개를 사용한다. 각성 랭크에 따라 밝기·폭·레이어 수가 증가한다.

SliceWeaponArt의 포즈별 좌표는 발광 위치에만 사용한다. 원본 캐릭터 스프라이트를 마스킹하거나 다른 무기를 얹지 않는다. 하린의 총구는 현재 프레임의 원본 총 끝을 따른다. F2 연출 완화는 빛의 강도와 파티클 수를 줄인다.

별도 무기 아틀라스 시험안은 최종 빌드에 포함하지 않는다.
