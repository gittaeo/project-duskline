# Font attribution

Source: Noto Sans KR from the Google Fonts repository.

- https://github.com/google/fonts/tree/main/ofl/notosanskr
- Original file: `NotoSansKR[wght].ttf`
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`.

The distributed `Resources/DuskFont.ttf` is a modified static instance at weight 500, generated with fontTools 4.65.0. Its family was renamed **Duskline Sans**, with style **Medium**. Original copyright and licensing metadata are retained. This avoids the very thin default variable-font instance in the Unity runtime while keeping Korean glyph coverage.

The font remains under the SIL Open Font License; it is not sold separately. fontTools is a build-time utility only and is not needed to open or build this project.
